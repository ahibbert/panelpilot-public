# Panel Pilot support — pre-release

Panel Pilot is currently preparing for release review. For pre-release defects, use the issue tracker and avoid including comic pages, credentials, private repository URLs, reading history, or other personal data. Security reports should use the private vulnerability channel.

- [Open a support issue](https://github.com/ahibbert/panelpilot-public/issues/new)
- [Report a security vulnerability privately](https://github.com/ahibbert/panelpilot-public/security/advisories/new)

Do not submit a formal copyright notice through a public issue. A monitored private copyright contact, operator identity, notice instructions, retention terms, and appeal process must be published before external distribution. Until that channel exists, the app remains blocked from public release.

The final public support page must add the operator name and monitored support, privacy, copyright, and security contact information required by applicable law and App Store Connect before public distribution.
