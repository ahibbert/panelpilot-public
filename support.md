# Panel Pilot support — pre-release

Panel Pilot is currently preparing for internal TestFlight. For pre-release defects or security concerns, use the issue tracker for this repository and avoid including comic pages, credentials, private repository URLs, reading history, or other personal data.

- [Open a support issue](https://github.com/ahibbert/panelpilot-public/issues/new)
- [Report a security vulnerability privately](https://github.com/ahibbert/panelpilot-public/security/advisories/new)

The final public support page must add the maintainer contact information required by applicable law and App Store Connect before public distribution.
