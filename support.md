# Panel Pilot support — pre-release

Panel Pilot is operated by Aydin Daniel Sareff-Hibbert in New South Wales, Australia.

Panel Pilot is currently preparing for release review. For pre-release defects, use the issue tracker and avoid including comic pages, credentials, private repository URLs, reading history, or other personal data. Security reports should use the private vulnerability channel.

- [Email support privately](mailto:panelpilotcontact@proton.me)
- [Send a privacy question or request](mailto:panelpilotcontact@proton.me)
- [Send a copyright or rights complaint](mailto:panelpilotcontact@proton.me)
- [Read the notice review and appeal process](appeals.html)
- [Open a support issue](https://github.com/ahibbert/panelpilot-public/issues/new)
- [Report a security vulnerability privately](https://github.com/ahibbert/panelpilot-public/security/advisories/new)

Do not submit a formal copyright notice through a public issue. The published notice and appeal process is an operational pre-release draft and must receive specialist approval before external distribution.

The shared monitored address is [panelpilotcontact@proton.me](mailto:panelpilotcontact@proton.me). The operator must keep it monitored and test the response process before public distribution.
